Population Split

Draw a boundary across the test region and try to divide its population as evenly as possible. This prototype requests population totals from WorldPop when you submit a split.

Central Indiana test region · click two points on the border

How to play

  1. Choose a data year and resolution.
  2. Click two points near the rectangle's border to draw a cut.
  3. Press Fetch & score to request both polygon totals.
  4. Try to get as close to a 50 / 50 split as possible.

The endpoints snap to the test region's edge to form two polygons.

API settings

Provider: WorldPop API v2. This endpoint returns polygon totals, not a population raster.

Prototype limitations

This tests live API requests and the slice UI. Browser CORS, API limits, unsupported years/resolutions, or provider task failures may prevent a request from completing.

For precise GeoSlice-style scoring, the game ultimately needs population grid cells so it can count the cells on each side of the line. Two polygon totals are a first API experiment, not a full production solution.
